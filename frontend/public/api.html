Authentification

L'API utilise OAuth2 + JWT. Obtenez votre paire client_id / client_secret dans les paramètres développeur.

# 1. Obtenir un access token
curl -X POST https://api.simplif-ia.fr/api/auth/token \
  -H "Content-Type: application/json" \
  -d '{"client_id":"sk_live_xxx","client_secret":"..."}'

# Réponse
{
  "access_token": "eyJhbGciOiJI...",
  "token_type": "Bearer",
  "expires_in": 1800
}

Exemple : envoyer une LRE

curl -X POST https://api.simplif-ia.fr/api/lre/send \
  -H "Authorization: Bearer eyJhbGciOiJI..." \
  -H "Content-Type: application/json" \
  -d '{
    "recipient": {
      "name": "CAF de Paris",
      "address": "50 rue du Dr Finlay, 75015 Paris"
    },
    "subject": "Recours préalable indu APL",
    "body": "Madame, Monsieur, ...",
    "attachments": ["doc-id-xxx", "doc-id-yyy"]
  }'

Webhooks

Recevez des événements en temps réel sur votre endpoint HTTPS :

  • user.created · nouvel utilisateur inscrit
  • demarche.completed · démarche finalisée
  • lre.sent · LRE envoyée
  • lre.delivered · LRE remise eIDAS
  • vault.upload · nouveau document
